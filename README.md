# Week 1 Task: Python for Machine Learning & Data Preprocessing

## Objective
Demonstrate Python, NumPy, Pandas, data cleaning, missing-value handling, categorical encoding, normalization, basic feature selection, and exploratory data analysis.

## Files
- `sample_student_data.csv` — illustrative dataset with missing values and a duplicate row.
- `preprocess.py` — complete preprocessing script.
- `preprocessed_student_data.csv` — output generated by running the script.
- `Week1_Report.docx` — report for submission.

## Run on a computer
Install Python, then run:
```bash
pip install pandas numpy
python preprocess.py
```

## Run in Google Colab (phone-friendly)
1. Open https://colab.research.google.com/
2. Create a new notebook.
3. Upload `sample_student_data.csv` and `preprocess.py`, or copy the code from `preprocess.py` into a cell.
4. Run the code. Pandas and NumPy are usually available in Colab.
5. Download `preprocessed_student_data.csv` after it is created.

## Notes
This is a small educational demonstration using fictional/illustrative student data, not real student records and not a trained machine-learning model. Review the code and be prepared to explain each step.
